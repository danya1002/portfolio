Советы по GitHub-профилю

Рекомендации от опытного наставника для создания профессионального портфолио

1

Публикуйте свои работы

GitHub — это ваше портфолио в IT. Работы вне колледжа показывают, что вы учитесь самостоятельно, а это ценится даже выше диплома.

2

Сделайте красивые README

Для каждого проекта напишите: что делает программа, как запустить, какие технологии использованы, добавьте скриншоты. Пустой репозиторий с кодом без описания = никому не нужный репозиторий.

3

Пиньте лучшие работы

На GitHub можно закрепить до 6 репозиториев — выберите самые сильные и разнообразные проекты.

4

Код должен быть чистым

Уберите «мусорные» файлы, добавьте .gitignore, напишите комментарии к сложным участкам. Работодатель смотрит не только на результат, но и на стиль.

5

Регулярность важнее объёма

Лучше 5 качественных проектов с регулярными коммитами, чем 50 «залитых за раз». Активный профиль с зелёными квадратиками выглядит живым и рабочим.

6

Не нарушайте NDA

Если проект делали для заказчика или компании — убедитесь, что в договоре нет запрета на публикацию. Своё личное портфолио — да, чужая коммерческая тайна — нет.

7

Ссылка на GitHub — в резюме

Прямая ссылка на профиль в шапке резюме повышает шансы, что HR откроет и оценит ваш уровень до собеседования.
